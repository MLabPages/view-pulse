# Experiment readiness

日付: 2026-09-02

## 目的

ViewPulse を実験セッションで使いやすい状態にする。参加者の区別、研究用の書き出し、画像刺激の提示制御を足し、画像記録を止められない不具合を直す。

## 確認したこと

- 記録データは JSON のみで、参加者IDがなく、複数人の後処理がしづらかった。
- 画像記録は提示開始後に記録ボタンが無効のままで、画面を閉じる操作以外で終了しにくかった。
- YouTube の時間帯別ヒートマップ要約が保存対象外だった。

## 変更

- 開始画面に任意の参加者ID・条件・メモ、画像の表示秒数を追加した。
- 分析JSONを schema 7 にし、品質要約と実験メタデータを入れた。CSV書き出しとライブラリ全件保存を追加した。
- 画像記録の停止ボタンを再有効化し、表示秒数による自動終了と、記録中の操作UI抑制、タブ閉鎖の確認を追加した。

- `node --check local-server.mjs`
- `node verify.mjs`
