# Architecture

## 概要

ViewPulse はビルド不要のブラウザアプリで、`index.html` が画面を持ち、`app.js` が入力・カメラ解析・記録・結果表示・ライブラリ保存を統括します。`local-server.mjs` はカメラ API とモジュール読み込みを確認するためのローカル配信を提供します。

## 処理の流れ

1. 端末内の画像・動画、または YouTube URL を入力する。
2. 解析への同意後、内カメラを取得し、WebEyeTrack または CPU 向け MediaPipe 虹彩特徴で視線を推定する。
3. 9 点を 3 巡する調整と、未使用 4 点の精度確認を行う。
4. 画像は経過時間、動画は再生時間、YouTube はプレイヤー時間に視線・表情サンプルを同期する。
5. 結果画面でヒートマップ、反応タイムライン、手動 AOI、実験的な動的 AOI、リアクション映像を表示する。
6. 記録は IndexedDB に保存し、共有・JSON/CSV 保存・ライブラリ再表示を行う。

## 外部境界

- WebEyeTrack、MediaPipe、物体認識モデルは初回に CDN / Google から読み込むが、選択コンテンツやカメラ映像は送信しない。
- YouTube は公式埋め込みプレイヤーを別ドメインで再生する。ViewPulse はその映像フレームを読み込まない。
- 同意した場合だけ内カメ映像を端末内に保存する。
