# Current state

最終更新: 2026-09-02

## 現在の状態

- 画像・動画・YouTube URL を入力できる Web/PWA アプリ。
- 内カメラ 1 台で表情と推定視線を解析し、画面上のコンテンツ時間と同期する。
- WebGL では WebEyeTrack、CPU 環境では MediaPipe 虹彩特徴を使うフォールバックがある。
- 9 点調整、4 点検証、顔位置ガイド、姿勢品質、ヒートマップ、反応タイムライン、手動 AOI がある。
- 開始画面で任意の参加者ID・条件・メモを付けられ、画像刺激は表示秒数で自動終了できる。
- 結果とライブラリから分析JSON（schema 7）とCSVを書き出せる。ライブラリは全件の数値データ一括保存ができる。
- 端末内動画の動的 AOI は実験機能として測定後に実行する。YouTube は対象外。
- 記録と任意の表情映像は IndexedDB に保存し、PWA の共有先として YouTube URL を受け取れる。

## 既知の注意点

- カメラ利用には HTTPS または localhost が必要。
- 視線は推定値であり、端末の揺れ・照明・眼鏡・顔位置で誤差が出る。低精度記録は大きな AOI の傾向に限定して解釈する。
- YouTube は公式プレイヤーの外部接続があり、ViewPulse からフレームを取得できない。
- IndexedDB はサイトデータ削除やプライベートブラウズで失われるため、重要な記録は共有またはファイル保存する。
- 動的 AOI の一般物体認識はブランド・ロゴ・価格・広告文を正確に識別できない場合がある。
- 結果画面の「次の記録へ」は刺激を残したまま開始画面に戻る。ページ全体の再読み込みはしない。
