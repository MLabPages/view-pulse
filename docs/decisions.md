# Decisions

## 2026-08-20: 作業記録をルート入口から分離する

- ルート `AGENTS.md` は、作業前に読む文書と壊してはいけない境界への案内に絞る。
- 現在の構成は `current-state.md`、設計上の判断はこのファイル、個別の作業は `dev/logs/` に記録する。
- `.webeyetrack-upstream/docs/` は同梱 upstream の資料として、ViewPulse の作業記録とは別にする。

## 既存機能として維持する判断

- ローカルファイルの解析と IndexedDB 保存を端末内に閉じる。
- YouTube は公式埋め込みを使い、URL・ID・分析値の同期に限定する。
- 視線調整は実測点と未使用点の検証を使い、低精度でも記録は可能にするが、結果の解像度を過大評価しない。
- 動的 AOI は測定後にだけ実行し、物体名の確認・除外を研究者に委ねる。
- 旧 `rear_blob` を非破壊で読み込める互換処理を維持する。

## 2026-09-02: 実験記録に参加者情報とCSVを足す

- 参加者ID・条件・メモは任意入力とし、既存の気軽な利用を止めない。
- 研究用の後処理のため、分析JSONに品質要約を入れ、UTF-8 BOM付きCSVも書き出す。
- 画像刺激は表示秒数を指定したときだけ自動終了し、空欄なら手動停止のままにする。
